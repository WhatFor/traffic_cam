# 0005. No CI

Date: 2026-10-05. Status: Accepted.

## Context

The build plan originally called for path-filtered GitHub Actions workflows: lint, type checks and tests for vision, build and test for ingest, a check that generated contract code is up to date, and a job that built the ingest container image. The project has one developer, working on one PC.

## Decision

There are no CI workflows. `just lint` and `just test`, run on the PC, are the checks.

## Consequences

- Nothing runs the checks automatically. A commit can break lint or tests without anyone being told.
- Generated contract code can go stale if the schema is edited without running `just gen-contracts`. Generation is deterministic, so regenerating and looking at the diff shows whether it has.
- Nothing builds a container image for ingest; see 0006 for how ingest is shipped instead.
